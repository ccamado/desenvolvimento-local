🔭 O que é o Método Científico?

O Método Científico é um caminho organizado para investigar problemas, testar ideias e chegar a conclusões baseadas em evidências — não em suposições ou "achismos"!

🎯 Usamos o Método Científico para garantir que a Central de Avisos resolva um problema REAL com base em dados REAIS.

🗺️ As 5 Etapas do Método Científico

1. 👁️ Observação
Percebo um problema ou fenômeno no mundo real.
Na Central: "Muitos alunos não sabem das provas com antecedência."
2. 💡 Hipótese
Formulo uma suposição que explique o problema.
Na Central: "O canal de comunicação atual não alcança todos os alunos."
3. 📋 Coleta de Dados
Reúno informações para testar a hipótese.
Na Central: Questionários, entrevistas, observação dos murais.
4. 📊 Análise
Examino os dados coletados em busca de padrões.
Na Central: 70% dos alunos não veem avisos no mural.
5. ✅ Conclusão
Confirmo ou refuto a hipótese com base nos dados.
Na Central: "Precisamos de um canal digital mais acessível."

💡 Por que isso importa?

Sem o Método Científico, poderíamos criar uma solução que não funciona! Com ele, sabemos o que realmente causa o problema antes de tentar resolvê-lo.

🏆 Método Científico = Decisões baseadas em DADOS, não em "acho que..."

📝 Resumo para o Caderno — Aula 3

  1. O Método Científico é um caminho organizado para investigar problemas e chegar a conclusões.
  2. A primeira etapa é a Observação: perceber um problema ou fenômeno no mundo real.
  3. A segunda etapa é a Hipótese: uma suposição provisória que explica o problema observado.
  4. A terceira etapa é a Coleta de Dados: reunir informações para testar a hipótese.
  5. A quarta etapa é a Análise: examinar os dados em busca de padrões e respostas.
  6. A quinta etapa é a Conclusão: confirmar ou refutar a hipótese com base nos dados.
  7. Refutar uma hipótese é um resultado científico válido — mostra a realidade como ela é.
  8. Na Central de Avisos, usamos o Método Científico para entender por que os avisos falham.
  9. Decisões baseadas em dados são mais confiáveis do que suposições sem evidências.
  10. O Método Científico garante que a solução desenvolvida resolva o problema real.
