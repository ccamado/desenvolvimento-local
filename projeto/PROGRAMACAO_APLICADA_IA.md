# Frente de Trabalho - Programacao Aplicada a IA I

## Papel da materia no projeto

Construir o sistema Central de Avisos na pratica, trabalhando entrada, processamento, saida, logica, testes e consultas.

## Foco tecnico atual

MVP 0:

- `index.html`: tela inicial do chat.
- `Main.gs`: `doGet()` para abrir o HTML e `responderPergunta()` com resposta de teste/mock.

## Microentregas para o index.html

1. Indicador "Processando..." enquanto o bot responde.
2. Botao "Limpar conversa".
3. Botoes de perguntas prontas.
4. Historico no navegador com `localStorage`.
5. Hora HH:mm em cada mensagem.
6. Painel "O que posso perguntar?" com exemplos clicaveis.

## Regra para ajudar alunos iniciantes

Quando o aluno pedir alteracao de codigo:

1. Explicar o que sera mudado.
2. Mostrar BLOCO ANTIGO.
3. Mostrar BLOCO NOVO.
4. Explicar as diferencas.
5. Entregar checklist de teste.

Evitar reescrever arquivo inteiro quando a mudanca for pequena.
